# Aba Usuários (sprite por @ + VIP) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / TDD. Steps use `- [ ]`.

**Goal:** Aba `/admin` "Usuários" pra definir sprite e VIP por @; VIP ganha coroa 👑 e aparece sempre.

**Architecture:** Persistência em `characters.local.json` (`overrides` + `vip`). Novo módulo servidor `users.js` + rotas em `admin-api.js`. Nova aba React. Overlay lê `vip` e renderiza coroa + heartbeat de presença.

**Tech Stack:** Node ESM, React+TS+Tailwind (admin), PixiJS (overlay), Vitest.

---

## Task 1: `src/server/users.js` + testes (TDD)

**Files:** Create `src/server/users.js`; Test `tests/users.test.js`.

Padrão de I/O = `src/server/sprites.js` (ler com `readJson`, escrever `characters.local.json` com `JSON.stringify(data, null, 2) + '\n'`, `overlayDir` injetável, base via `overlayBase`). Validação de sprite reusa `listSprites` de `sprites.js`.

- [ ] Escrever testes primeiro (`tests/users.test.js`), usando um `overlayDir` temporário com um `characters.json` (contendo `overrides: { matheusmonck: 'luffy' }` e uns `characters`) e um `characters.local.json`. Casos:
  - `listUsers` une override default (`matheusmonck`→`luffy`, source `default`) + entradas locais + vips; retorna `{username, sprite, source, vip}`.
  - `setUser({username:'joao', sprite:'<id local válido>'})` grava `overrides.joao` no local; `listUsers` reflete source `local`.
  - `setUser({username:'joao', sprite:''})` remove o override local de joao.
  - `setUser({username:'joao', vip:true})` adiciona joao em `vip`; `vip:false` remove.
  - `setUser` com sprite inexistente lança erro.
  - `removeUser('joao')` limpa override local + vip de joao.

- [ ] Implementar `src/server/users.js` com `listUsers`, `setUser`, `removeUser` (assinaturas do spec). Ids válidos = `listSprites({overlayDir}).map(s=>s.id)`.

- [ ] Commit: `feat(users): módulo users.js (override+vip em characters.local.json)`.
